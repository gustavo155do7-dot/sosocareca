Build a complete, modern and responsive website for an AI English learning platform.

The website's main purpose is to help Portuguese-speaking Brazilians **actually learn to speak English naturally**, especially for everyday conversations, online gaming, Discord and talking to English-speaking people.

Do NOT create a traditional English-learning website focused mainly on grammar exercises and memorizing vocabulary.

The platform should feel like **an AI friend + English teacher**.

## 1. WEBSITE DESIGN

Create a modern, attractive and professional interface.

Style:

* Dark modern UI
* Black/dark gray background
* Blue/purple accent colors
* Smooth animations
* Rounded cards
* Modern typography
* Responsive on PC, tablet and mobile
* Gaming/technology-inspired aesthetic
* Clean interface without being cluttered

The homepage should immediately explain:

**"Learn to SPEAK English. Not just memorize it."**

Subtitle:

**"Practice real conversations, gaming slang, everyday English and talk with AI like you're talking to a real person."**

Add a prominent button:

**"Start Learning"**

## 3. AI ENGLISH TEACHER

The most important feature is an AI conversation teacher.

Create a chat interface where the user can talk to the AI.

The AI should behave like a friendly English-speaking person and teacher.

The user should be able to choose:

* Beginner
* Intermediate
* Advanced

The AI should adapt automatically to the user's level.

The AI should teach:

* Everyday English
* Natural expressions
* Casual English
* Internet slang
* Gaming slang
* Discord English
* Voice chat English
* Pronunciation
* Listening
* Conversation
* Grammar when necessary

The AI should NOT constantly interrupt the conversation with grammar explanations.

Instead, let the user communicate naturally and correct mistakes afterward.

## 4. REAL CONVERSATION MODE

Create a mode called:

**REAL TALK**

The AI starts a natural conversation.

Example:

AI:
"Yo bro, what's up?"

User responds.

The AI continues naturally.

If the user makes a mistake, show:

**Your sentence:**
"I no understand."

**Natural correction:**
"I don't understand."

**More natural:**
"I don't get it."

**Portuguese:**
"Eu não entendo."

Then continue the conversation.

The user must always have the opportunity to respond before the AI continues.

## 6. SLANG DICTIONARY

Create a searchable slang dictionary.

Users can search words and expressions.

Each result should show:

* Expression
* Meaning in Portuguese
* Natural pronunciation
* Example sentence
* Context
* Formality level
* Whether it is appropriate for gaming/chat

Categories:

* Gaming
* Internet
* Discord
* Everyday
* American slang
* British slang
* Texting

Also distinguish between normal slang, rude expressions, insults and offensive language.

## 7. DAILY ENGLISH

Create a section called:

**Daily English**

Every day generate a small lesson containing:

* 5 everyday expressions
* 5 gaming expressions
* Pronunciation practice
* Mini conversation
* Quick challenge

Do not overload the user.

Focus on phrases that people actually use.

Example:

**I'm heading home.**

Meaning:
"Estou indo para casa."

Natural pronunciation:
"I'm hedin' home."

## 8. PRONUNCIATION TRAINING

Create a pronunciation section.

Show:

Formal:
**What are you going to do?**

Natural:
**What are you gonna do?**

Explain how native speakers connect and shorten words.

If browser microphone functionality is available, allow the user to record their voice.

Create a pronunciation practice interface with:

**Listen → Speak → Compare → Try Again**

If actual speech recognition is implemented, analyze the user's pronunciation and give simple feedback.

## 9. LISTENING PRACTICE

Create a listening mode.

The AI gives the user a natural English sentence.

Example:

**"Yo, you wanna hop on?"**

The user must choose what they understood.

Options:

A. Do you want to play/join?
B. Do you want to leave?
C. Are you going home?

Then explain the answer.

Gradually increase the difficulty.

## 13. CHAT UI

Include:

* User messages
* AI messages
* Typing animation
* Send button
* Microphone button
* "Translate" button
* "Explain" button
* "Correct me" button

The user can click **Explain** on an AI sentence to understand it in Portuguese.

The user can click **Translate** when they don't understand something.

## 14. AI PROMPT SYSTEM

Create a dedicated system prompt for the English teacher AI.

The AI must:

* Speak naturally
* Adapt to the user's level
* Avoid unnecessary grammar lectures
* Encourage the user to speak
* Correct important mistakes
* Teach natural expressions
* Teach slang appropriately
* Use Portuguese explanations when necessary
* Gradually reduce Portuguese as the user improves
* Remember recurring mistakes
* Simulate realistic conversations
* Never simply dump vocabulary lists
* Always make the learning interactive
